# Frontend · UI Developer

기초에 강하고 실무에서 꾸준히 발전해온 UI 개발자

## ⭐ About Me

다양한 환경에서 크로스 브라우징과 시멘틱 마크업, 반응형 구축을 꾸준히 경험해왔습니다.

스타일 가이드가 정교한 브랜드 사이트부터 대규모 서비스의 리뉴얼 업무까지 다양한 프로젝트에 참여하며 마크업 및 UI 구조 설계, 유지보수, 접근성 고려 등의 실무 역량을 쌓았습니다.

특히 브랜드 프로모션 페이지, 랜딩 페이지, 관리자 UI 등 다양한 성격의 화면을 빠르게 구축해 온 경험을 통해 요구사항을 정확하게 파악하고 일관된 UI를 구현하는 능력을 갖추게 되었습니다.

또한 새로운 기술 환경에도 빠르게 적응해, React·Next.js·Styled Components·Emotion·SCSS·Axios·TanStack Query 등 현대적인 프론트엔드 스택 기반에서도 마크업과 간단한 API 연동을 수행하며 프로젝트를 안정적으로 마무리한 경험이 있습니다. 이 과정에서 PHP 페이지를 Next.js 기반으로 부분 리뉴얼하여 성능 개선에
기여하기도 했습니다.

업무 성향은 책임감이 강하고, 맡은 일은 끝까지 완성하는 스타일입니다. 투명하게 이야기하고 필요한 상황에서는 직접적으로 소통하는 편이라 협업 과정에서도 신뢰를 바탕으로 작업을 이어가는 것을 중요하게 생각합니다.

기초가 튼튼하고, 새로운 환경에서도 꾸준히 발전해온 UI 개발자입니다.
